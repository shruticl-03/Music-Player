🎧 Web Music Player

A fully functional, responsive music player built using HTML, CSS, and JavaScript. This project offers a clean and user-friendly interface that allows users to play, pause and view real-time song progress. It’s perfect for learning DOM manipulation and event handling in JavaScript.

✨ Features:
🎵 Play, Pause, Next, and Previous buttons
📀 Displays song title, artist name, and album art
📊 Progress bar with real-time updates and manual seeking
🔁 Auto-play next song
📱 Fully responsive layout for mobile and desktop

🛠️ Built With
HTML5 – Markup structure
CSS3 – Responsive styling & transitions
JavaScript (Vanilla) – Interactivity and logic
